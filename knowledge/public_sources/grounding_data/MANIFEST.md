# ONGC Public Grounding Data — MANIFEST

Collected 19 Oct 2026 (system date) by curl from official public sources. Every PDF was checked with `file` and `pdfinfo`; page counts are listed below. Text was extracted with `pdftotext -layout` into `text/<same name>.txt`. For the three latest ARs there is also a `_flow.txt` (non-layout) version, which reads two-column narrative pages more cleanly.

**Page citation convention used in FACTS.md:** `p.N` means the **PDF page index** (1-based), which matches the `\f` page split in the text files. In AR FY2025-26 the printed folio = PDF page − 2 (e.g. PDF p.23 = printed p.21). Other ARs have similar small offsets.

## Not obtained / attempted
- **DPE Public Enterprises Survey, MoU ratings, CAG audit reports, PPAC/DGH asset-wise production:** not downloaded in this time box. MoU rating is marked as unverified in FACTS.
- **Sansad Q&A index:** the API at `https://sansad.in/api_ls/question/qetFilteredQuestionsAns` works, but its filters are ignored, so the full index has to be paged. The full 18th LS was scanned (34,720 questions); the 17th LS and Rajya Sabha were not.
- **Grade-wise (E0-E9) headcount and pay scales:** ONGC does not publish these on its website. The "Pay" page is an online payment gateway, not pay scales.
