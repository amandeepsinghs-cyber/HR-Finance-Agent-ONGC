## What changed
- **Exports (path traversal):** one `DocumentExporter.safe_path()` for every writer — base name only, safe characters, writer-fixed extension, resolved path must stay inside the exports folder. Export ids are 128-bit random (`exp_<32 hex>`); download accepts only minted ids, checks folder containment and an extension allow-list. Files older than 1 h are swept (Cloud Run disk is RAM). Agent-side exports mint ids and never return server paths to the model; Google-Docs dry-run copies download under their id. Errors return a generic message.
- **Proxy (`server.js`):** HTTPS backends (Cloud Run) for HTTP and the WebSocket upgrade (TLS + SNI); when the browser aborts, the backend request is cancelled; a backend dying mid-stream ends the client response instead of hanging.
- **Container:** Dockerfile gates the image on `lint:tokens`, `lint:contrast` and `tsc`; planner on by default (`YUKTI_PLANNER=1`, rollback by env); Playwright browser download skipped; `.dockerignore` drops local-only folders and tests. `start_cloudrun.sh` waits up to 60 s for backend health and fails fast if the process dies, supervises both processes (`wait -n`), forwards SIGTERM for clean shutdown.
