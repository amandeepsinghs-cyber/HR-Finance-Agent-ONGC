## 1. Files Changed (P4.4 Backend Scope)

1. `yukti/backend/app/brain/chart_rules.py` (and re-exports in `yukti/backend/app/tools/chart_rules.py`)
   - Added `ALL_KINDS` (20 kinds in exact order matching `yukti/frontend/src/charts/compat.ts`: `bar`, `hbar`, `donut`, `pie`, `line`, `area`, `histogram`, `scatter`, `treemap`, `waterfall`, `funnel`, `grouped_bar`, `stacked_bar`, `stacked_100`, `combo`, `heatmap`, `box`, `gauge`, `bullet`, `table`).
   - Added `DataProfile`, `profile(visual)`, `compatibility(p, kind)`, and `kinds_for(visual)` mirroring `yukti/frontend/src/charts/compat.ts` (including Round-2 fixes `cb0a01b`):
     - `combo`: requires `>= 2` measures and `shape != "single"`, else `line` (on `time`) or `bar` with note.
     - `stacked_100`: requires `>= 2` measures, `not has_negative`, and `shape != "single"`, else `table` (on `single`) or `bar` with note.
     - `heatmap`: requires `>= 2` text categories + `>= 1` measure, or `records` with `>= 2` groupable columns, else `bar` with note.
     - `box`: requires pre-computed quartiles (`min..max`), `records` with measure, repeated `dim_key` with measure, or `n >= 10` with measure + category, else `bar` with note.
     - `gauge`: requires `shape == "single"` and `has_target`, else `bullet` (if `has_target`) or `table` with note.
     - `scatter`: requires `>= 2` measures (no fabricated rank axis), else `line` (on `time`) or `bar` with note.
     - `histogram`: never on `time` (`-> line` + note) and never on `categorical` with `< 30` values (`-> hbar` + note).
     - `pie` / `donut` (`PART_OF_WHOLE`): never on `time` (`-> bar` + note) and never on negatives (`-> hbar` + note).
     - `line` / `area` on nominal `categorical` (`not ordinal`) -> `bar` + note.
     - `funnel` / `waterfall` on nominal positive `categorical` -> `hbar` + note.
   - Updated `select_chart_kind` so value + % time series defaults to `"combo"` and 1-row with target defaults to `"gauge"`.
2. `yukti/backend/tests/test_compat_parity.py` (new)
   - Runs TypeScript `yukti/frontend/src/charts/compat.ts` directly via Node and asserts 100% parity between Python and TypeScript across all 14 canonical shapes (9 from `scripts/test_compat.ts` + 5 from `src/fixtures/charts/portfolioA/*.json`) × all 20 `ALL_KINDS` (`280` compatibility cells + `14` `DataProfile` checks + explicit P4.4 rule and default-kind assertions = `296` tests).
