## Result
- **CORS:** `allow_origins` comes from `YUKTI_ALLOWED_ORIGINS` (comma list). A `*` entry is logged as an error and dropped, so the list is never `*` with credentials. Methods are `GET, POST`; headers are `Content-Type, Authorization`. Before this step the list was `[…, "*"]` with `allow_credentials=True`, `allow_methods=["*"]` and `allow_headers=["*"]`.

## Decisions (recorded for G4)
- **Default allow-list** = packet default (`http://localhost:3300,http://127.0.0.1:3300`) **plus** `http://localhost:3200,http://127.0.0.1:3200`, because the second local UI (:3200) is in daily use. Both UIs reach the backend through the same-origin proxy (`server.js`), so browsers never preflight; the list matters only for direct cross-origin callers. Cloud Run must set `YUKTI_ALLOWED_ORIGINS` to its own origin (see P0.9 notes).
- **Non-admin token on `/admin/*` → 401, not 403.** This follows the checklist wording "401 without admin claim".
- `/health` stays public (SPEC-06 §4.7).
