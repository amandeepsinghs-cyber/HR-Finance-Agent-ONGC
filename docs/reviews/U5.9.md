## 2. U5.9 Chart Excellence Review Rounds

### Round 1 → Round 2 Fixes (`73810cd1`)
- **`EChart.tsx`:** Changed `chart.setOption(option, { replaceMerge: ['series','xAxis','yAxis','grid'] })` to `chart.setOption(option, { notMerge: true })` to prevent residual `polar`, `radar`, `title`, and `graphic` objects from bleeding across chart switches (`g04`, `g06`, `g07`, `g17`, `g18`).
- **Reduced motion (`options.ts`):** Added `anim()` helper checking `window.matchMedia('(prefers-reduced-motion: reduce)').matches` across all option builders (C7: 2 → 5).
- **Waterfall connector lines (`g10`):** Added subtle dashed step-connector series (`z: 1`, `lineStyle: { color: t.grid, type: 'dashed' }`) linking cumulative bar tops/bottoms.
- **Bullet chart target callout (`g11`):** Replaced overlapping per-row `"Target"` text with a clean legend header (`| Target`, `■ Actual`) and crisp vertical target tick markers.
- **Line & Stacked Bar small multiples (`g17`, `g18`):** Added multi-panel grid support for `line` and `stacked_bar` when `mixedUnits` is true (`₹ Cr` in Panel 1, `MMT` in Panel 2).
- **Histogram density overlay (`g19`):** Added smooth spline density curve (`smooth: 0.45`, dashed neutral stroke) with explicit legend (`Bin Frequency`, `Density Curve`).

### Round 2 → Round 3 Fixes
- **`g13` Small Multiples shared domain (C2: 3 → 5):** When small-multiples panels share the same unit kind (e.g., both `%`), `ChartRenderer.tsx` computes a shared `niceBounds(0, ...allValues)` domain and passes `opts.domain` to `rankedOption`, aligning the `0%` baseline and making bar lengths directly comparable across panels.
- **`g14` Scatter direct labels & leader lines (C3: 3 → 5):** Added `makeScatterPlacer` in `options.ts` which registers all marker bounding boxes first, sets `hideOverlap: false` for `≤ 8` points, evaluates 8 candidate offsets away from nearest neighbor markers, and draws subtle leader lines (`showAbove: false`) so all 6 points (`CBM Bokaro`, `Tripura Asset`, `Cauvery Asset`, `Rajahmundry Asset`, `Bassein & Satellite`, `Eastern Offshore`) are cleanly labelled with zero overlap.
- **`g11` Bullet neutral outline (C1/C4: 5/5):** Replaced semantic red fill on the lowest performer (`90.3%`) with a neutral outline (`stroke: t.text, fill: 'transparent'`) while keeping the bar fill primary blue.
- **`g19` Histogram legend swatch & dark halo token (C4/C8: 5/5):** Added explicit solid legend swatch (`itemStyle: { color: t.accent }`) for `Bin Frequency` and updated dark-theme `--yk-chart-label-halo` in `tokens.json` to `#1A1C22` (matching `--yk-bg-card`).
