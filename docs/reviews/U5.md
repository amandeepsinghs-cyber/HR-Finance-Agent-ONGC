## What changed (user-visible)
- **Any chart, any way:** one engine (`src/charts/compat.ts`) re-plots an answer as bar, H-bar, donut, pie, line, area, histogram, scatter, treemap, waterfall, funnel, grouped / stacked bar, bullet or table — from the toolbar, by voice ("show as pie") or typed — with identical output, in ~100 ms, no backend call. If a type doesn't fit the data, Yukti shows the nearest honest alternative with a one-line reason ("A pie can't show losses, so gains and losses are shown as bars"). Histogram → pie keeps slices = bins. Matrix: [`docs/chart_compatibility.md`](../chart_compatibility.md).
- **Named roster** for people questions: search, grade / discipline filters, sort, multi-select, "Draft transfer note (N)" and Export (N); masked columns show a lock with the policy reason; aggregate-only banner for junior roles; smooth on 2,000 rows.
- **Comparison view** (e.g. Delhi HQ vs Mumbai): KPIs per entity + one shared-axis grouped bar with a difference tooltip.
- **Insights with kinds** (headline / trend / outlier / risk) and **drill-down chips** that send a `spec_patch` with the follow-up.
- **Mixed units never share one axis** (U5.6 part): e.g. ₹ Cr + % + MMT become small multiples.
- Visual audit of the 89-question bank: [`docs/visual_audit.md`](../visual_audit.md).
