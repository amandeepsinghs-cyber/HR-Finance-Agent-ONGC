## 5. Deviations & Alignment Notes

- **None from spec.** Per `@coordinator` alignment (#12):
  1. Small deductions (`<2%` of revenue) are accumulated within each segment and flushed as a single `"Other expenses (net)"` delta bar immediately before the next `subtotal`/`end` row (never across a subtotal).
  2. `yukti/backend/app/brain/presenter.py` was updated in-scope so `pnl_statement` builds its waterfall chart via `app.brain.bridge.bridge()` (removing the old EBITDA-plug `"Operating Expenses"` derivation) and preserves `line_code` in `disp_cols` across all statement tables (`pnl_statement`, `balance_sheet`, `cash_flow_statement`, `financial_ratios`) for frontend `compat.replot` classification.
  3. Because the codebase imports `from app.tools.chart_rules import ...` across existing modules while `P4.1.md` specifies `yukti/backend/app/brain/chart_rules.py`, `yukti/backend/app/brain/chart_rules.py` holds the canonical implementation and `yukti/backend/app/tools/chart_rules.py` re-exports it cleanly.
