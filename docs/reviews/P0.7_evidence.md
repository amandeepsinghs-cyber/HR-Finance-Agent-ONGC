# P0.7 evidence — "Illustrative" labels on synthetic clauses (JRTP Rev 4, R16)

**Step:** P0.7 · **Branch:** `v3/P0-stabilise` · **Bug:** BUG-31 · **Decision:** D-35 · **Spec:** SPEC-07 §4.2, SPEC-11 §7.2 · **Status:** pre-G4

## Result
Every clause in the rulebook index now carries `provenance`. The value flows through policy search into the contract (`visual.clause.provenance`, an extra field the schema already allows), and the clause card shows an **"Illustrative"** badge with the tooltip "Synthetic clause for demo; ONGC's text is not public." The hard-coded JRTP fallback title is gone, and the "Legal Authority: … statutory force" note now appears only for `real` clauses.

## Data decision: all 68 rows are `illustrative` (0 `real`)
Packet rule: `real` only where `source_doc` is a public ONGC/DPE/court document on disk. The CSV has no `source_doc`; `source_basis` names the *inspiration* (judgments J-xx, circulars P1-xx, DPE G-xx). None of the clause texts is verbatim from a public document on disk:
- `knowledge/public_sources/policies/MANIFEST.md` ("Not found / not obtainable") lists JRTP as *referenced only*, Leave Rules 1995 and the R&P Regulations as *excerpts only*, PRBS and Post-Retirement Medical as *partial*, the HR Manual as TOC only, and BDP as *not public*.
- Spot checks show the composed texts disagree with the real documents. "Post-retirement medical Clause 1.0" cites "Office Order No. 30/2015 dated 01.07.2015"; the manifest's P1-19 is dated **19.06.2015**. "PRBS Clause 4.0" cites "Circular No. 73 dated 20.04.2018"; P1-10 is dated **29 Nov 2018**.
- The 12 R16 rows (new since v0.1; `source_basis = "ONGC HR/Finance Policy Documents"`) are Gemini-generated (BUG-31).
- The real Delhi HC citation in SPEC-07 §4.2 (J-03) is a separate citation, not a row of this index, so the packet example "Delhi HC 2018 J-03 → real" does not map to any CSV row.

The financial notes corpus that policy search also loads (`financial_build/data/financial_notes_corpus.jsonl`, shown as "ONGC Annual Report (FYxx)") is generated text, so it is marked `illustrative` too.
