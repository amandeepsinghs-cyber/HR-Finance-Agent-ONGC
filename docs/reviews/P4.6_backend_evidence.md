## 1. Export API Shape for `P4.7` Frontend Wiring

### 1.1 `POST /api/export`
- **Auth:** Requires session cookie (`yk_session`) or `Authorization: Bearer <token>`.
- **Request Body (`ExportRequest`):**
  ```json
  {
    "turn_id": "turn-sess-123-001",
    "session_id": "sess-123",
    "format": "xlsx | csv | pdf | docx | eml | sheets | docs",
    "columns": ["name", "functional_designation", "grade", "delhi_tenure_years"],
    "chart_png": "data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAA...",
    "chart_svg": "<svg ...>...</svg>",
    "email_draft": {
      "from": {"name": "Arun Mehra, CMD", "email": "cmd@ongc.example"},
      "to": [{"name": "Director (HR)", "email": "director.hr@ongc.example"}],
      "cc": [],
      "subject": "Review requested: ...",
      "body_md": "As discussed...",
      "citations": ["JRTP Rev 4 clause 3.2 (Illustrative)"]
    },
    "title": "Optional title override",
    "content": "Optional markdown fallback (CMD/DIR_HR only when turn_id is omitted)",
    "rows": []
  }
  ```
  *(Note: `contract` has been removed from `ExportRequest` in Round 2 so callers cannot supply arbitrary pre-shaped contracts.)*
- **Response (`200 OK`):**
  Returns both the nested `artifact` object (`SPEC-10 §5`) and flat top-level fields for backward compatibility with existing callers:
  ```json
  {
    "export_id": "exp_9f8a7b6c5d4e3f2a1b0c9d8e7f6a5b4c",
    "kind": "xlsx",
    "format": "xlsx",
    "filename": "yukti_pnl_standalone_fy22-fy26_cmd_20261024-0500.xlsx",
    "url": "/api/export/exp_9f8a7b6c5d4e3f2a1b0c9d8e7f6a5b4c",
    "rows": 17,
    "columns": ["label", "FY26", "FY25", "FY24", "FY23", "FY22"],
    "masked": false,
    "created_at": "2026-10-24T05:00:00Z",
    "expires_at": "2026-10-25T05:00:00Z",
    "sha256": "e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855",
    "artifact": {
      "export_id": "exp_9f8a7b6c5d4e3f2a1b0c9d8e7f6a5b4c",
      "kind": "xlsx",
      "filename": "yukti_pnl_standalone_fy22-fy26_cmd_20261024-0500.xlsx",
      "url": "/api/export/exp_9f8a7b6c5d4e3f2a1b0c9d8e7f6a5b4c",
      "rows": 17,
      "columns": ["label", "FY26", "FY25", "FY24", "FY23", "FY22"],
      "masked": false,
      "created_at": "2026-10-24T05:00:00Z",
      "expires_at": "2026-10-25T05:00:00Z",
      "sha256": "e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855"
    },
    "toast": "Google Sheets isn't connected yet, so I've downloaded an Excel file. In Sheets, use File → Import to open it."
  }
  ```
  *(Note: `toast` is present only when `format` is `"sheets"` / `"docs"` or when user-requested `columns` were dropped by RBAC/synonym intersection. Never contains `docs.google.com`.)*
- **Error Responses:**
  - `401`: Missing or invalid session token.
  - `403`: `turn_id` belongs to a different principal (`SPEC-10 §4.10` item 1).
  - `400`: Unsupported format.

### 1.2 `GET /api/export/{export_id}` (and alias `GET /api/download/{export_id}`)
- **Auth:** Requires the session token of the **creating principal** (`emp_id` & `persona` match).
- **Headers:** `Content-Disposition: attachment; filename="<canonical_filename>"`, appropriate MIME type (`application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`, `text/csv; charset=utf-8`, `application/pdf`, `application/vnd.openxmlformats-officedocument.wordprocessingml.document`, `message/rfc822`, `application/zip`).
- **Error Responses:**
  - `403`: Requesting principal does not match creator principal (`BEH-04.50`).
  - `404`: Non-minted ID, missing file, or expired artifact (`> 24h` TTL).

### 1.3 `POST /api/export/audit` (for client-side `png` / `svg` exports)
- **Request Body (`ExportAuditRequest`):**
  ```json
  {
    "turn_id": "turn-sess-123-001",
    "session_id": "sess-123",
    "format": "png | svg",
    "filename": "optional_client_filename.png",
    "rows": 10,
    "columns": ["label", "value"],
    "masked": false
  }
  ```
- **Response (`200 OK`):**
  ```json
  {
    "status": "ok",
    "filename": "yukti_report_corp_asof-20261019_cmd_20261024-0500.png",
    "audit": { "...audit row..." }
  }
  ```

## 6. Round 2 G4 Review Fixes (`M1`–`M6`, `S1`–`S8`)

All 6 Must-Fix (`M1`–`M6`) and 8 Should-Fix (`S1`–`S8`) items from `docs/reviews/P4.6.md` are resolved:

- **M1 (Client-supplied data untrusted & RBAC enforcement):**
  - Removed `contract` from `ExportRequest` (`app/main.py`).
  - When `turn_id` is explicitly provided and not found in the server turn registry or `SessionManager`, `POST /api/export` fails closed with `403` (never falls back to client-supplied `rows`/`content`).
  - When `turn_id` is omitted: (a) `CMD` and `DIR_HR` may export client-supplied `rows`/`content` after `enforce_export_rbac`; (b) for `DIR_FIN` and all junior personas (`E1..E4`), free markdown `content` without `turn_id` is refused with `403`, client statements are refused with `403`, and client `rows` must either contain a verifiable `grade`/`level` key (in which case they collapse to `grade/headcount` with `<5` small-cell suppression and strip all personal/unrecognized columns like `full_name`, `staff_no`, `posting`, `basic_pay`) or use only safe aggregate columns (`_SAFE_JUNIOR_AGG_COLS`, with `<5` suppression and `masked=True`); otherwise refused with `403`.
  - `_validate_statement_rbac` in `app/export_audit.py` inspects `visual.statement` rows/labels/codes and rejects personal/salary statements for non-`CMD`/`DIR_HR`.
- **M2 (Fail-closed download & sidecar persistence):**
  - `register_artifact` raises if sidecar `.exp_<id>.meta.json` cannot be written, failing the export (`500`) rather than leaving an unverified file.
  - `verify_artifact_access` and `download_export` (`GET /api/export/{export_id}` and `/api/download/{export_id}`) fail closed: if `rec is None` (missing record/sidecar or expired), any orphan `exp_<id>.*` files on disk are unlinked and `404` is returned; principal mismatch raises `TurnOwnershipError` (`403`).
- **M3 & M4 (Formula injection escaping in `.xlsx` and `.csv`):**
  - Added `_safe_cell_text` in `app/tools/export_tool.py`: strings starting with `=`, `+`, `-`, `@`, `\t`, or `\r` (after optional leading whitespace) are prefixed with a leading apostrophe `'` (`cell.data_type = "s"` in `openpyxl`). Numeric negative values (`int`/`float`) are unaffected, and server-generated DCF formula sheets remain exempt.
  - Applied across `.xlsx` (title/subtitle/banner, headers, statement labels, tabular cells, `Definition` sheet) and `.csv` (headers, statement labels/codes, tabular cells, and multi-table `.zip` CSVs).
- **M5 (Unified 24-hour TTL & sidecar-aware sweep):**
  - Unified `DEFAULT_EXPORT_TTL_SECONDS = 86400` (`YUKTI_EXPORT_TTL_SECONDS`, default 24h) in both `app/export_audit.py` and `app/main.py`.
  - `sweep_expired_exports` (called by `_sweep_old_exports`) reads `.exp_*.meta.json` `expires_epoch` so valid artifacts are retained for the full 24h and expired artifacts have both their data file and sidecar deleted together (while orphan files without sidecars are swept after 1h).
- **M6 (Voice/live turn registration & `SessionManager` fallback hardening):**
  - Registered turns via `register_turn_contract` across `/api/voice-turn` (`app/main.py`), `live_session.py` (`_run_turn`, `finalize_turn`, `run_text_turn`), and `turn_runner.py` (`execute_turn_async`), stamping `sess.emp_id`.
  - `resolve_turn_contract` `SessionManager` fallback verifies both `emp_id` and `persona` (refusing if `t_emp_id` is missing or mismatched) and restores full `sess.last_rows` when `visual.table.rows` was capped at 50 (or surfaces the 50-row cap in `toast`).
- **S1–S8:**
  - **S1:** Passed `norm_p` directly to `enforce_contract(c, norm_p)`.
  - **S2:** Replaced `norm_p.startswith(("E1", ...))` with `persona_class(norm_p) == "junior"`.
  - **S3:** Validated `.eml` headers against CR/LF injection (`400`) and applied `html.escape()` to `body_md` lines before building HTML fallback.
  - **S4:** Passed canonical `.xlsx` attachment filename into `export_eml` and unlinked temporary `_attachment.xlsx` after attaching.
  - **S5:** Added `_SafeWeasyPrintURLFetcher(weasyprint.urls.URLFetcher)` in `app/tools/pdf_export.py` allowing only `data:image/png;base64,...` and `file://` URLs inside `FONTS_DIR`.
  - **S6:** Ignored default `"Yukti_Export"` placeholder in `filename_from_contract` and added `visual.chart.title` fallback.
  - **S7:** Updated `NAMING_REGEX` to allow `.zip` and wired multi-table CSV exports (`len(comp_items) >= 2`) to `.zip` in `app/main.py` and `app/tools/export_tool.py`.
  - **S8:** Verified turn ownership (`403` on mismatch) and computed `masked` server-side in `POST /api/export/audit`.
