## 6. Deviations and open items
1. **Scope beyond the packet (per D-45 and the parent brief):** the NSE provider and fetcher were added, even though packet §4 said not to build them. More than 5 files changed because of this.
2. **Beta (lead decision, 23-Oct 10:14):** the current 2-year weekly beta (FY26/FY27, computed in P1.9) uses the NSE weekly pull in §7. **Historical FY17–FY25 betas use the Damodaran EM oil & gas E&P industry beta** (`betaemerg`, re-levered), flagged `beta_method=industry_proxy` per SPEC-02. No weekly history before the 2-year window is fetched.

4. The real Yahoo JSON structure is assumed to match the documented `timeseries.result[].meta.type` envelope; the parser also accepts the packet's flat form. Packet stop-and-ask trigger: compare when real files arrive.

## 7. Beta weekly pull (lead decision 23-Oct 10:14, within D-45)
**Result: we now have 104 of 104 weekly closes for ONGC and NIFTY 50 (weeks ending 2024-10-25 to 2026-10-16), from 214 NSE requests with no 403 or 429.**

- **Method:** `python -m financial_ssot.extract.market_provider --fetch-nse-weekly 104`.
  - For each week it tries Friday first and steps back one day on a 404 (holiday).
  - Requests were ≥3 s apart, plain GET, no cookies. The run started 10:16Z and ended 10:27Z.
  - 214 requests = 206 file downloads + 8 holiday 404s. The 2025-03-28 files were already on disk, so they were not requested again.
- **Holiday weeks** (the Thursday close was used): 2024-11-15, 2025-03-14, 2025-04-18, 2025-08-15, 2026-04-03, 2026-05-01, 2026-06-26 and 2026-10-02.
- **Manifest:** `nse/_fetch_manifest.csv` now has 226 rows, one per stored file. All sha256 values were re-checked against the files on disk (`SHA_OK`).
- **API:**
  - `NseArchiveProvider.weekly_closes(ticker, start, end)` returns W-FRI weekly closes.
  - `MarketChain.weekly_closes(...)` returns `(DataFrame, provider)`.
  - P1.9 computes the beta from these.
- **Sanity check only** (not the P1.9 deliverable): 103 weekly log returns ending 2026-10-16 give β_raw 0.737, Blume-adjusted 0.824, R² 0.141. This is inside the W2 band (0.2–2.0, R² ≥ 0.05). The closes are unadjusted, so dividends are ignored in the returns; ONGC had no split or bonus in the window.
- **Historical FY17–FY25 betas:** these use the Damodaran EM oil & gas E&P industry beta (`betaemerg` of that year, re-levered), flagged `beta_method=industry_proxy` per SPEC-02. No weekly NSE history before 2024-10 was fetched.
- **Coverage gap for the FY26 FY-end beta:** the FY26 row needs 104 weeks ending 30-Mar-2026, but the pull covers only about 74 of those weeks (from Oct-2024). So the FY26 FY-end beta is either a shorter-window estimate or the industry proxy — decide in P1.9. The current trailing beta is complete.
- **Tests:** `test_yahoo.py` 24 passed, 1 skipped; the full suite is 156 passed, 1 skipped.
