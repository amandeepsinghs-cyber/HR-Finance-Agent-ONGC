2. **Environment note:** the previous UI servers on :3200/:3300 ran inside a different network namespace (a sandboxed shell of an earlier session) and could only reach a backend in that namespace. After the backend restart they returned `Backend unreachable`. They were rebuilt from the current `src/` and restarted the same way (`cwd=fe_build`, `NODE_ENV=production PORT=<p> node server.js -p <p>`) in the host namespace; both now proxy to the new backend (`/health` 200 through :3200 and :3300). Restart scripts: `scratch/restart_backend.sh`, `scratch/restart_frontend.sh` (agent scratch dir, not in the repo).
3. `yukti/frontend/tsconfig.tsbuildinfo` changes on every `tsc`; it is not committed.
