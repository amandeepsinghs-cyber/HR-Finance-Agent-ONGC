## Must-fix (blocking)

### M1. Unconditional formatless fallback in `resolveExportIntent` hijacks P4.1 Hindi re-plots, P2H.4 Hindi send/email commands, and EN/HI data questions ([exportIntent.ts:31-53](../../yukti/frontend/src/services/exportIntent.ts#L31-L53), [uiCommands.ts:223-229](../../yukti/frontend/src/services/uiCommands.ts#L223-L229))

- **Cause:** `VERB_RE` ([exportIntent.ts:31-32](../../yukti/frontend/src/services/exportIntent.ts#L31-L32)) matches bare `\b(export|download|save|...)\b` as well as `सेव|भेजो|में\s+(दो|दे\s*दो|बनाओ|डाउनलोड)` anywhere in the string. When no format word in `LEXICON` matches, lines 49–52 unconditionally return `{ format: 'png' | 'xlsx', defaulted: true }`, which `parseUiCommands` ([uiCommands.ts:224-228](../../yukti/frontend/src/services/uiCommands.ts#L224-L228)) intercepts before the re-plot rules and executes in 0 ms in the browser as `{ action: 'export', value: 'auto' | 'png:default' | 'xlsx:default' }` instead of routing to the re-plot engine or backend.
- **Reproduced false positives (12 of 27 reviewer adversarial probes):**
  1. **P4.1 Hindi re-plots broken** (`resolveExportIntent` runs at [uiCommands.ts:224](../../yukti/frontend/src/services/uiCommands.ts#L224) before [uiCommands.ts:268](../../yukti/frontend/src/services/uiCommands.ts#L268) `/^(इसे|इसको|यह)\s.*(दिखाओ|दिखाइए|बनाओ)$/` and matches `में बनाओ`):
     - `"इसे वॉटरफॉल में बनाओ"` → `[{"action":"export","value":"auto"}]` (expected `chart_kind: 'waterfall'`)
     - `"इसे बार चार्ट में बनाओ"` → `[{"action":"export","value":"png:default"}]` (expected `chart_kind: 'bar'`)
     - `"इसे टेबल में बनाओ"` → `[{"action":"export","value":"xlsx:default"}]` (expected `chart_kind: 'table'`)
     - `"इसको लाइन चार्ट में बनाओ"` → `[{"action":"export","value":"png:default"}]` (expected `chart_kind: 'line'`)
  2. **P2H.4 Hindi send-to-person / email requests hijacked as local exports:**
     - `"इसे डायरेक्टर को भेजो"` → `[{"action":"export","value":"auto"}]` (must go to backend)
     - `"यह सूची डायरेक्टर एचआर को भेजो"` → `[{"action":"export","value":"xlsx:default"}]` (must go to backend P2H.4 email flow)
     - `"सीएमडी को यह रिपोर्ट भेजो"` → `[{"action":"export","value":"auto"}]` (must go to backend)
  3. **EN + HI domain/data questions containing `export` / `save` / `सेव` / `भेजो` hijacked as local exports:**
     - `"crude oil export volume in fy26"` → `[{"action":"export","value":"auto"}]`
     - `"export credit scheme applicability in ongc"` → `[{"action":"export","value":"auto"}]`
     - `"can we save ₹500 crore in opex this year?"` → `[{"action":"export","value":"auto"}]`
     - `"save cost in drilling operations"` → `[{"action":"export","value":"auto"}]`
     - `"मुझे दिल्ली के आंकड़े भेजो"` → `[{"action":"export","value":"auto"}]`
     - `"ओएनजीसी का कच्चा तेल एक्सपोर्ट कितना है?"` → `[{"action":"export","value":"auto"}]`
     - `"बचत कैसे करें और खर्च कैसे सेव करें?"` → `resolveExportIntent` returns `{"format":"xlsx","defaulted":true}`
- **Fix:**
  1. Only allow the **formatless default branch** ([exportIntent.ts:48-52](../../yukti/frontend/src/services/exportIntent.ts#L48-L52)) when the utterance uses a dedicated export/download verb (`export|download|एक्सपोर्ट|डाउनलोड`) paired with an explicit target or demonstrative (`this|it|that|the\s+(chart|graph|plot|visual|table|statement|balance\s+sheet|roster|list|rows)|यह|इसे|इसको|इस|चार्ट|ग्राफ|टेबल|तालिका|सूची`, or bare `^(export|download|एक्सपोर्ट|डाउनलोड)(\s+करो|\s+करें|\s+कीजिए)?$`). Never trigger a formatless default from `save`, `सेव`, `भेजो`, or `में (दो|दे दो|बनाओ)`.
  2. Reject recipient-directed sends (`/\b(send|email|mail|forward)\b.*\bto\s+(the\s+)?(director|cmd|hr|finance|board|chairman|gm|ed|officer|team|manager)/i` and `/(डायरेक्टर|निदेशक|सीएमडी|अधिकारी|बोर्ड|टीम|एचआर)\s+को\s+(भेजो|ईमेल)/`) unless an explicit `.eml` / `email file` / `outlook draft` format word is present.
  3. Extend `NOT_EXPORT_RE` ([exportIntent.ts:35](../../yukti/frontend/src/services/exportIntent.ts#L35)) to include Hindi question words (`क्या|कैसे|कितना|कितने|क्यों|कौन`) and domain collocations (`\b(export\s+(volume|credit|duty|tariff|revenue|sales|target)|save\s+(cost|costs|money|crore|opex|capex)|can\s+we\s+save|how\s+much)\b/i`).

### M2. `\bsheets?\b` in the `xlsx` lexicon entry breaks BEH-04.46 (`"Export this statement to Sheets"`) and overrides Balance Sheet exports to PDF/CSV/Word ([exportIntent.ts:19-28](../../yukti/frontend/src/services/exportIntent.ts#L19-L28))

- **Cause:** `LEXICON` has `['sheets', /\b(google\s*sheets?|g\s?sheets?)\b|गूगल\s*शीट/i]` at line 19 and `['xlsx', /\b(excel|xlsx|xls|spreadsheet|workbook|sheets?)\b|एक्सेल|स्प्रेडशीट/i]` at line 22 (ahead of `csv`, `pdf`, `svg`, `png`, `docx`).
- **Impact A — BEH-04.46 & Packet §6 regression:** The BEH-04.46 / Packet §6 verbatim `"Export this statement to Sheets"` (and `"export to sheets"`) resolves to `format: 'xlsx'` instead of `format: 'sheets'`. In [AnswerCard.tsx:372](../../yukti/frontend/src/components/AnswerCard.tsx#L372), `honestWorkspaceCopy` is only selected when `format === 'sheets' || format === 'docs'`, so the user gets `"Your Excel file is ready."` instead of the required SPEC-10 §4.7 toast (`"Google Sheets isn't connected yet, so I've downloaded an Excel file. In Sheets, use File → Import to open it."`).
- **Impact B — Balance Sheet format override:** Because `"balance sheet"` (and `"fact sheet"`) contains the singular word `sheet`, `"export the balance sheet to pdf"`, `"download the balance sheet as csv"`, and `"export the balance sheet to word"` all match `xlsx` at line 22 before reaching `pdf`, `csv`, or `docx`:
  - `resolveExportIntent("export the balance sheet to pdf")` → `{"format":"xlsx","defaulted":false}` (expected `'pdf'`)
  - `resolveExportIntent("download the balance sheet as csv")` → `{"format":"xlsx","defaulted":false}` (expected `'csv'`)
  - `resolveExportIntent("export the balance sheet to word")` → `{"format":"xlsx","defaulted":false}` (expected `'docx'`)
- **Fix:**
  1. Remove `sheets?` from `xlsx` ([exportIntent.ts:22](../../yukti/frontend/src/services/exportIntent.ts#L22)): `['xlsx', /\b(excel|xlsx|xls|spreadsheet|workbook)\b|एक्सेल|स्प्रेडशीट/i]` (matching SPEC-10 §4.8).
  2. Match plural `sheets` in prepositional export phrases on the `sheets` entry ([exportIntent.ts:19](../../yukti/frontend/src/services/exportIntent.ts#L19)): `['sheets', /\b(google\s*sheets?|g\s?sheets?|(?:to|in|into|as)\s+sheets)\b|गूगल\s*शीट/i]`.
  3. Include `balance\s+sheet` in the `table` target regex ([exportIntent.ts:42](../../yukti/frontend/src/services/exportIntent.ts#L42)) so formatless `"export the balance sheet"` still resolves to `target: 'table'` → `xlsx` (`defaulted: true`), while `"export the balance sheet to pdf"` resolves to `pdf` (`defaulted: false`).
  4. Add `पीएनजी` to the `png` lexicon entry ([exportIntent.ts:26](../../yukti/frontend/src/services/exportIntent.ts#L26)) so `"इस चार्ट को पीएनजी में डाउनलोड करो"` resolves with `defaulted: false` (matching `सीएसवी`, `पीडीएफ`, `एसवीजी`).
