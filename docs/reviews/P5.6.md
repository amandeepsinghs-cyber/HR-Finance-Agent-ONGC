### 1.1 `principal_from_request` Cookie Fallback (`yukti/backend/app/auth.py:354-370`)
- **Code under review:**
  - [`yukti/backend/app/auth.py:357-369`](file:///usr/local/google/home/amandeepsinghs/o&g%20agentic%20transformation/Oil%20&%20Gas%20Agent%20Portfolio/cloud_run_apps/HR%20and%20Finance_ONGC__v3P5/yukti/backend/app/auth.py#L357-L369):
    ```python
    auth = request.headers.get("authorization") or request.headers.get("Authorization")
    if auth and auth.lower().startswith("bearer "):
        tok = auth.split(" ", 1)[1].strip()
        p = verify_token(tok)
        if p is not None:
            return p
        cookie_tok = request.cookies.get(SESSION_COOKIE)
        if cookie_tok:
            return verify_token(cookie_tok)
        return None
    ```
- **Why this is safe (No BUG-06 / BUG-36 regression, No SPEC-06 / D-64 bypass):**
  1. **No unsigned or unverified fallback:** When Cloud Run's IAM layer or `gcloud run services proxy` injects `Authorization: Bearer <Google-OIDC-JWT>`, `verify_token(tok)` parses the header, sees `alg: "RS256"` (`!= "HS256"` at [`auth.py:324`](file:///usr/local/google/home/amandeepsinghs/o&g%20agentic%20transformation/Oil%20&%20Gas%20Agent%20Portfolio/cloud_run_apps/HR%20and%20Finance_ONGC__v3P5/yukti/backend/app/auth.py#L324)), and returns `None`. The fallback then reads `request.cookies.get("yk_session")` and passes it through **`verify_token(cookie_tok)`**.
  2. **Cryptographic & directory validation on `yk_session`:** `verify_token` ([`auth.py:314-351`](file:///usr/local/google/home/amandeepsinghs/o&g%20agentic%20transformation/Oil%20&%20Gas%20Agent%20Portfolio/cloud_run_apps/HR%20and%20Finance_ONGC__v3P5/yukti/backend/app/auth.py#L314-L351)) enforces:
     - `header.get("alg") == "HS256"` ([`auth.py:324`](file:///usr/local/google/home/amandeepsinghs/o&g%20agentic%20transformation/Oil%20&%20Gas%20Agent%20Portfolio/cloud_run_apps/HR%20and%20Finance_ONGC__v3P5/yukti/backend/app/auth.py#L324));
     - constant-time HMAC-SHA256 verification via `hmac.compare_digest(expected_sig, got_sig)` using `_signing_secret()` ([`auth.py:329-332`](file:///usr/local/google/home/amandeepsinghs/o&g%20agentic%20transformation/Oil%20&%20Gas%20Agent%20Portfolio/cloud_run_apps/HR%20and%20Finance_ONGC__v3P5/yukti/backend/app/auth.py#L329-L332)), where `_signing_secret()` refuses to start in `YUKTI_ENV=prod` without a dedicated `YUKTI_JWT_SECRET` ([`auth.py:277-284`](file:///usr/local/google/home/amandeepsinghs/o&g%20agentic%20transformation/Oil%20&%20Gas%20Agent%20Portfolio/cloud_run_apps/HR%20and%20Finance_ONGC__v3P5/yukti/backend/app/auth.py#L277-L284));
