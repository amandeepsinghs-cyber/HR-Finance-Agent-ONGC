## What changed
- **Orb (U3.1/U3.2):** `VoiceOrb.tsx` rewritten as a Canvas-2D infinity ribbon (4 lemniscate ribbons, AI Aura colours from tokens, soft halo). Idle breathes slowly; listening and speaking follow the real mic / output level; thinking runs a soft pulse along the ribbon. DPR-aware; pauses off-screen and in hidden tabs; reduced motion draws a static frame per state; `aria-pressed` for the mic toggle. Greeting orb scales with the fluid type scale (rem) so it keeps proportion on 4K.
- **Honest levels (U3.3):** `getRawMicLevel()` (raw worklet RMS, also on the ScriptProcessor fallback) and `getOutputLevel()`; `getMicLevel()` is a pure read; SpeechRecognition no longer injects synthetic levels.
- **Barge-in (U3.4):** leaky counter on the raw level (4 × 50 ms); local stop drops the rest of the reply and sends `interrupt`; backend suppresses audio only while Gemini is still generating, cleared on Gemini's `interrupted`, `turn_complete` or a new user transcript; `acceptIncoming()` on every new user turn.
- **Mic lifecycle (U3.5):** in-flight start shared (no second stream), stop-during-start releases and returns `cancelled` (no error banner), `dispose()` closes the playback context on unmount.
- **SpeechRecognition fallback (U3.6):** used only when Live voice is really available (`isLiveVoiceReady()` = socket open and not `degraded`); per-recognizer `cancelled` flag; no relaunch on fatal errors; stale socket `onopen/onerror/onclose/onmessage` guarded.
- **Performance (U3.7):** found that the CSS aura bloom animation, not the orb, dropped 4K to 16 fps. The bloom is now static with no blur filter; the orb's halo carries the breathing.
