# P0.4 evidence — server-side persona token; no free-text role switching; audit log

**Step:** P0.4 · **Branch:** `v3/P0-stabilise` · **Bug:** BUG-06 · **Feature:** FEAT-031 · **Spec:** SPEC-06 §4.4, §4.6 (R-ROLE), §4.8 · **Behaviour:** BEH-01.03/.04/.07 · **Status:** pre-G4

## Result
**An E-level user can no longer become CMD by voice or text.** The persona now comes only from a backend-signed session token. The request body, the WebSocket query string, WS `config` frames, the ADK `ui_control` tool, Gemini Live tool calls and the frontend's local command parser can no longer change it.

| Layer | Change |
|---|---|
| `app/auth.py` (new) | HS256 JWT `{sub, persona, function, grade, is_admin, demo, iat, exp=iat+8h, jti}` via stdlib `hmac`/`hashlib`; rejects `alg` ≠ `HS256` (incl. `none`), bad signature, expired, unknown persona → 401. `Principal`, `require_principal`, `require_admin`, IAP stub (fails closed), role-switch detector (EN/HI/Hinglish), R-ROLE copy, JSONL audit (`logs/access_audit.jsonl`, SPEC-06 §4.8 fields; question text stored only as a hash). |
| `main.py` | `GET /api/auth/personas`, `POST /api/auth/session` (sets `yk_session`: HttpOnly; Secure; SameSite=Strict; 8 h), `GET /api/auth/me`. `/api/turn`, `/api/voice-turn`, `/api/export`, `/api/export/{id}` depend on `require_principal` (401 without a token). The body `persona` is ignored, and a mismatch is audited `persona_assertion_ignored`. `/ws/live` authenticates from the upgrade cookie/bearer or a first `{"type":"auth","token"}` frame, else closes 4401. DEMO_ADMIN switches mint a new admin token (`admin_persona_switch`). Any other `set_persona` ui_action is stripped. |
| `turn_runner.py` | The principal is threaded through. A deterministic role-switch guard runs before every fast path, planner and LLM call: non-admin → R-ROLE contract (`access.status=refused`, rule `SPEC-06 §4.4 R-ROLE`), audit `role_switch_denied`. Post-turn RBAC now always uses the session persona; it used to use the *contract* persona for non-juniors, which was the escalation path. |
| `ui_control.py` | `validate("persona", …)` always returns an R-ROLE error, so the ADK and Live tools cannot switch. |
| `live_session.py` | `principal` fixes `self.persona`. WS `config.persona` is ignored and audited. The voice `ui_control` persona action → R-ROLE + audit. The principal is passed to all 4 `execute_turn_async` calls. |
| `access_control.py` | `normalize_persona` no longer coerces (unknown/empty → `UnknownPersona`). `answer_composer.py` catches it while repairing a contract. |
| Frontend | `page.tsx`: signs in (`/api/auth/session`) before opening the socket, resumes an existing session via `/api/auth/me`, and re-signs every 2 h. The TopBar picker is the demo "Sign in as…". The page stops adopting `contract.persona`, and a backend `set_persona` only re-reads `/api/auth/me`. `uiCommands.ts`: the local "switch role to …" parser was removed. `server.js`: proxies `/api/auth/*`. |

## Decisions / deviations (recorded for G4)
1. **No PyJWT.** It is not installed and the packet says "stop and ask before adding", and lockfiles are off-limits. HS256 is implemented with the standard library (about 40 lines, constant-time compare, strict `alg` check), so no dependency was added.
2. **Dev signing key:** the packet says "random per-process key + warning". The running backend uses `--workers 2`, so a per-process key would make roughly half of requests 401. The fallback is a random 32-byte key in a 0600 file in the OS temp dir (outside the repo), shared by local workers, with a warning log. Production must set `YUKTI_PERSONA_SIGNING_KEY` from Secret Manager (P0.9 doc).
3. **Token not returned in the JSON body** (HttpOnly by design). The WS is authenticated by the same-origin cookie on the upgrade; a first-frame token is also accepted for non-browser clients.
4. **Files beyond the packet's list:** `answer_composer.py` (catch `UnknownPersona` during repair), `frontend/server.js` (proxy `/api/auth/*`; without it the UI cannot sign in), `frontend/src/services/uiCommands.ts` (its local parser switched persona from typed text), `tests/test_api_export.py` + `tests/test_export_security.py` (bearer fixtures), `tests/test_rbac_policy.py` (1 assertion, see above), `.gitignore` (`yukti/backend/logs/`).
5. **Admin voice switching** over Gemini Live is not supported in P0 (a socket cannot set a cookie). Admin switches work by text; voice → R-ROLE. Follow-up for P2H.2.
6. Not in P0.4: `/api/auth/session` rate limit (SPEC-06 §4.7) and download ownership checks (`export_audit.emp_id`). Left for P2H.2 / P4.6.
7. Frontend scripts that call `/api/turn` directly (`scripts/smoke_test.js`, `live_e2e_test.js`) now need a session cookie or bearer token. Noted for P0.6/P5.
