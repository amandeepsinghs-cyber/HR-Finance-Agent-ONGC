**CHANGES REQUESTED.** The statement parser's numbers are right: 0 wrong values in ~110 values I checked by hand against the AR text. The A = E + L, PAT-chain and cash-tie checks use AR-printed totals, and there are no plug lines. Two defects need fixing before Approve:

- **(B2)** The notes parser silently writes wrong or partial values when numbers get absorbed into the label. One example: AR FY18 DD&A total for FY17 = 21,895.38 instead of 121,895.38.

Both fixes are small and local.
