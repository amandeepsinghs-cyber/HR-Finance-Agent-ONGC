## Deviations (for the reviewer)
1. **Backend lexicon** (`yukti/contracts/intents/export_intent.json`, `ui_control.py`) is **not** in this commit. The intents file is created by P2H.4 on `v3/P2H-hr`, so adding it here would cause a merge conflict. The frontend lexicon is the single source until P2H.4 adopts it.
2. **Table/statement PNG not offered.** `html-to-image` is not a dependency (packet stop-and-ask). Tables export as xlsx/csv/pdf; "image of the table" falls back to xlsx and says so.
3. **No vitest** in the project, so the intent tests run as a `tsx` script, like the existing `test_*.ts` scripts.
