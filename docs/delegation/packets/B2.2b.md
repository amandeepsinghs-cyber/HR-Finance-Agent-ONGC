## 6. Comparator reference
```python
def norm_filter(f):  # -> (field, op, value) hashable
    v = f["value"]
    if isinstance(v, list): v = tuple(sorted(str(x) for x in v))
    elif isinstance(v, (int, float)) and not isinstance(v, bool): v = float(v)
    else: v = str(v)
    return (f["field"], f["op"], v)
```
For `filters`, compare `set(map(norm_filter, got))` to the expected set. `period` absent in expect ⇒ not checked; present ⇒ `got.get("period", {})` restricted to keys fy/from/to must equal it exactly.
