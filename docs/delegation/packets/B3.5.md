## 5. Exact requirements
1. Signature: `def draft_transfer_note(self, employees: List[Dict[str, Any]], context: Optional[Dict[str, Any]] = None, version: int = 1) -> Dict[str, Any]`.
2. `employees` rows use the roster keys: `emp_id, name, designation, grade, discipline, work_centre, ongc_tenure_years, station_tenure_years, years_to_retirement, retiring_within_3yr, exemption` (any may be missing → show "—").
3. Return `{"doc_type": "transfer_note", "title": ..., "markdown": ..., "template_id": "template_transfer_note.docx", "version": version, "employee_count": N, "emp_ids": [...]}`; title = `"Draft Transfer Note: {N} Executive(s) — {work centre}"` where work centre is the common `work_centre` if all rows share it, else `"Multiple Work Centres"`.
4. Markdown sections (exact headings): `# OIL AND NATURAL GAS CORPORATION LIMITED`, `## CORPORATE HUMAN RESOURCES | DRAFT TRANSFER NOTE`, `**Classification:** CONFIDENTIAL — DELIBERATIVE DRAFT (JRTP Clause 11.0)`, `### 1. Purpose`, `### 2. Employees Proposed for Transfer ({N})` with a markdown table of **all** N rows (no truncation; columns: S.No, Name, Emp ID, Designation, Grade, Discipline, Present Work Centre, Station Tenure (yrs), ONGC Service (yrs), Exemption), `### 3. Policy Basis` (JRTP Clause 3.2 rotation after 5 years; Clause 7.0 exemption within 3 years of superannuation), `### 4. Exemptions to Verify` listing employees with `retiring_within_3yr` true or `exemption` not in (None, "None", "", "—") — or the line "No exemption flags among the selected employees.", `### 5. Proposed Destination` with a one-line placeholder "To be decided by the competent authority (Director HR).", and a footer `*Prepared by:* Yukti AI for Director (HR) review`.
5. Numbers: tenure values formatted with 1 decimal; booleans as Yes/No.
6. If `employees` is empty → raise `ValueError("no employees selected")`.
7. Apply `sanitize_fictional_names` to the markdown, like `draft()`.
