## 5. Exact requirements
1. **Rows:** accept object rows or array rows (zip arrays with `columns`). Column order = `table.columns`. Header labels via `humanizeKey`. Numbers right-aligned `tabular-nums`, Indian grouping (`fmtNum`); `continuous_stay_years` with 1 decimal + " yrs".
2. **Toolbar (top):** search box (matches any of `emp_name`, `emp_id`, `name`, or the first text column; case-insensitive; `data-testid="roster-search"`), filter selects for categorical columns with 2–20 distinct values (prefer `grade`, `discipline`, `work_centre`; `data-testid="roster-filter-<col>"`, first option "All"), a count line "Showing N of M" (`data-testid="roster-count"`; M = `total_rows ?? rows.length`), and Export button (exports the *filtered* rows, or the selection if any).
3. **Sort:** click a header to sort asc → desc → original (`aria-sort` set; numeric-aware; `data-testid="roster-sort-<col>"`).
4. **Select:** leading checkbox column; header checkbox selects all *filtered* rows (indeterminate state when partial). Selection persists across sort/filter.
5. **Action bar:** when ≥ 1 row selected, a sticky bar (bottom of the table card) shows "N selected", one button per `row_actions` entry allowed for `persona` (`min_role` ordering: CMD > DIR_HR = DIR_FIN > E3_FIN = E2_HR; hide actions above the persona) labelled `<label> (N)` (`data-testid="roster-action-<id>"`), "Export (N)", and "Clear". Clicking calls `onRowAction(id, selectedRows)` / `onExport(columns, selectedRows)`.
6. **Masking:** for `masking.level === 'partial'`, masked column headers show a `Lock` icon with `title` = `reason (rule_ref)`; masked cells render muted "••••" with `aria-label="hidden by policy"`. For `level === 'aggregate'` or `'refused'`, show a top banner (`data-testid="roster-masking-banner"`) with the reason + rule_ref, disable selection and row actions.
7. **Virtualisation (no new deps):** fixed row height (2.5rem), a scroll container of `height`, render only visible rows + 8 overscan using `transform`/spacers; sticky header. Must stay ≥ 55 fps while scrolling 2,000 rows.
8. Empty state ("No matching people") when filters exclude everything.
9. Accessibility: `role="grid"` semantics or a proper `<table>`; keyboard: space toggles a focused row checkbox; buttons have labels.
