## 5. Exact requirements
1. Page layout: `max-w-[1400px] mx-auto p-8 space-y-10` on `bg-[var(--canvas)] min-h-screen overflow-auto h-screen` (the global `html, body { overflow: hidden }` requires the page container to scroll itself).
2. Header: `CardHeader`-style title "Yukti Design System" + a theme `Toolbar` (`light` | `dark`) that toggles `document.documentElement.classList` `dark`, and supports `?theme=dark` in the URL on mount.
3. Sections (each a `Card` with a `CardHeader` eyebrow + title), each with `data-testid="ds-<section>"`:
   - **Typography** (`ds-typography`): one line per scale step (display, headline, title, body, label, caption) + a tabular-numerals sample (`₹1,32,508 Cr`, `23,117`, `21.5%`).
   - **Colour tokens** (`ds-colours`): swatches (rounded squares with label) for `canvas, card, surface, surface-2, ink, ink-2, ink-3, hairline, accent, accent-deep, accent-pale, intel, positive, warning, critical, maroon, brand-saffron, brand-petrol` using `style={{ background: 'var(--<token>)' }}`, plus `--chart-cat-1 … 9` and `--chart-seq-1 … 6`.
   - **Primitives** (`ds-primitives`): Cards in 3 variants (raised/flat/glass, side by side), Chips (default, selected, with an icon from `lucide-react`, sm/md), Badges (all 7 tones, one with `dot`), `ContextChips items={['CMD','Delhi HQ','Executives','FY26']} source="SSOT"`, a `Toolbar` with 5 chart types, `IconButton` (normal + active).
   - **KPI** (`ds-kpi`): `KpiRenderer` with 3 KPIs (e.g. Active employees 23,117; FY26 Revenue ₹1,32,508 Cr; Vacancy rate 8.5% with a delta). Build the props per its interface.
   - **Table** (`ds-table`): `TableRenderer` with 6 columns × 8 rows (name, grade, discipline, ONGC tenure yrs, Delhi tenure yrs, retiring ≤3y) of fake data.
   - **Reference charts** (`ds-charts`): a responsive 2-column grid of 6 `Card`s, each fixed height `h-[380px]`, rendering `<ChartRenderer isDark={dark} spec=… />` for:
     1. `bar`: headcount by work centre (8 rows)
     2. `hbar`: FY26 PBT by field (10 rows, **including 2 negative values**, unit `₹ Cr`)
     3. `donut`: executives by grade E1–E9 (use the numbers from `c1_donut_by_grade.json`)
     4. `line`: revenue FY17–FY26 (unit `₹ Cr`)
     5. `histogram`: employee age values (≥ 120 raw numbers between 22 and 60; use `kind: 'histogram'`, data rows like `{ age: 34 }`, `value: 'age'`)
     6. `treemap`: capex by asset (8 rows)
     Each card title names the chart type; put the data in `samples.ts`.
4. Use the `isDark` state for `ChartRenderer`. All styling via tokens and Tailwind classes; **no colour literals**.
