## 1. Goal
A script that checks WCAG 2.1 contrast for defined foreground/background token pairs in both themes, and fails the build on regressions.

## 2. Context
- `src/design/tokens.json`: `themes.light` / `themes.dark` (hex or `rgba(...)` values), `chartPalettes`.
- WCAG relative luminance: `L = 0.2126 R + 0.7152 G + 0.0722 B`, with sRGB linearisation `c <= 0.03928 ? c/12.92 : ((c+0.055)/1.055)^2.4`; contrast = `(L1+0.05)/(L2+0.05)`.
- `rgba(r, g, b, a)` foregrounds/backgrounds: **alpha-composite** over the pair's base before computing (for a background with alpha, composite over the theme's `canvas`; for a foreground with alpha, composite over the given background).

## 3. Files you may change
1. **New:** `scripts/check_contrast.mjs`
2. `package.json`: **only** add `"lint:contrast": "node scripts/check_contrast.mjs"` to `scripts`

## 4. Do NOT touch
- `tokens.json` or any other file. If a pair fails, **report it**; don't change colours.
- **No** `git` commands, deploys, `bq` writes or destructive commands. Leave changes uncommitted.

## 5. Exact requirements
1. Read `src/design/tokens.json`. For **each theme** (`light`, `dark`) evaluate these pairs (fg on bg → minimum):
   | Class | Pairs | Min |
   |---|---|---|
   | Body text | `ink` on `canvas`, `card`, `surface`, `surface-2` | 4.5 |
   | Secondary text | `ink-2` on `canvas`, `card`, `surface` | 4.5 |
   | Tertiary/caption text | `ink-3` on `card` | 3.0 |
   | Accent text/links | `accent-deep` on `card` (light theme) / `accent-soft` on `card` (dark theme) | 4.5 |
   | Status text | `positive` on `positive-pale`; `warning` on `warning-pale`; `maroon` on `maroon-pale` | 4.5 |
   | On-fill text | `on-accent` on `accent`; `on-accent` on `maroon` | 3.0 (large/bold UI text) |
   | Chart text | `chart-text` on `card`; `chart-sub` on `card` | 4.5 |
   | Data marks (non-text) | every `chartPalettes.<theme>.categorical[i]` on `card` | 3.0 |
   | UI boundaries | `hairline` on `card` | **report only**, not failing (hairlines are decorative; just print the ratio) |
2. Print a table per theme: `class | fg | bg | ratio (2 dp) | min | PASS/FAIL/INFO`.
3. Exit 1 if any non-INFO pair fails; else print `[lint:contrast] OK (N pairs checked)`.
4. Pure Node (no dependencies).
