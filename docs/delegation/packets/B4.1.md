## 5. Exact requirements (each returns `Optional[Insight]`; must put every number used in the text into `facts`)
1. **delta_vs_last_year** (`type="delta"`, kind `trend`, priority 15): needs `ctx.prev_rows` and `ctx.prev_label`. Current total vs previous total of `value_col` (sum for additive units; for non-additive units only when exactly 1 row each side). Text: `"{metric_label} is {up|down} {abs_change} ({pct:+.1f}%) vs {prev_label}."` where abs_change uses `fmt(...,unit)`; `"unchanged vs {prev_label}"` when equal. Return None if previous total is 0 or missing.
2. **vs_target** (`type="vs_target"`, kind `risk` if any category misses the target else `comparison`, priority 12): needs `ctx.targets` (category → target). For each category in rows with a target: gap = actual − target. Text names the category with the largest shortfall: `"{cat} is {fmt(gap)} below {target_label} ({fmt(actual)} vs {fmt(target)})."`; if none below: `"All {n} categories meet the {target_label}."`. `ref` = that category.
3. **outliers** (`type="outlier"`, kind `outlier`, priority 25): robust z-score on per-category values (aggregate_by_dim for additive units, row values otherwise) with ≥ 5 categories: `z = 0.6745*(x-median)/MAD`; flag |z| > 3.5 (if MAD == 0 return None). Text: `"{cat} is an outlier at {fmt(x)} (median {fmt(median)})."` for the most extreme one; `ref` = cat.
4. **concentration** (`type="concentration"`, kind `note`, priority 30): additive units, ≥ 4 categories: share of the top 3 in the total. Return only if top-3 share ≥ 50%: `"The top 3 ({a}, {b}, {c}) hold {share:.1f}% of the total."`
5. **named_exceptions** (`type="named_exception"`, kind `risk`, priority 18): additive or not, if any value is negative: `"{k} negative: {cat1} ({fmt}), ..."` (max 3 names, most negative first) where k = count (e.g. "1 is negative: Champang (−₹4.93 cr)"). Use the actual negative values in facts.
6. **policy_flags** (`type="policy_flag"`, kind `risk`, priority 16): only for roster rows (`ctx.grain == "row"` and rows have `station_tenure_years`): count rows with `station_tenure_years >= 5` (rotation due, JRTP 3.2) and rows with `retiring_within_3yr` true (exempt, JRTP 7.0). Text: `"{due} of {n} are past the 5-year rotation norm; {exempt} are within 3 years of superannuation (exempt)."` n = len(rows).
