### Exact requirements
1. Input: the non-`_flow` `.txt` files for FY17, FY18 (English), FY19, FY22, FY23, FY24, FY25, FY26 in `knowledge/public_sources/grounding_data/text/`.
2. Split by page (`\f`); never cross a page boundary. Within a page, make chunks of 300–600 tokens (whitespace tokens × 1.3 ≈ tokens) with a 60-token overlap. Collapse runs of spaces; keep numbers as written.
3. Section: carry the last matched section heading forward across pages; the page range of each section is reported.
4. `note_no`: when inside notes, the current note number (`^\s*(\d{1,2})\.\s+[A-Z]`).
5. `line_codes`: dictionary match of `dim_financial_line.ar_labels` (read `financial_ssot/dim_financial_line.csv` when present; otherwise skip and leave empty) and of keywords (royalty, cess, SAED, windfall, exploratory well, dry well, depletion, impairment, decommissioning, lease, receivable, inventory, exchange loss).
6. `chunk_id` = `AR_FY26_p0098_c02`; `text_sha256`; drop chunks with < 40 tokens or > 60% digits (tables are already in the SSOT).
7. Output `financial_ssot/out/doc_chunks_ar.jsonl` (no embeddings) + `financial_ssot/out/doc_chunks_summary.csv` (per FY: pages, chunks, by section).
