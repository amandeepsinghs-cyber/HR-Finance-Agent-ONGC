## 5. Exact requirements
1. `pages.page_of_line(text_path, line_no) -> int` = 1 + number of `\f` characters before that line. `pages.folio(text_path, pdf_page) -> str | None` = the printed page number found in the last non-empty line of that page (regex `Annual Report 20\d\d-\d\d\s+(\d{1,3})` or a leading/trailing 1–3 digit token).
2. `numbers.parse_token(s)`: `"1,325,081"`→1325081.0; `"(7,720)"`→−7720.0; `"-"`→(0.0, is_nil=True); `"1.66 : 1"` and `"1.55:1"`→1.66/1.55 with unit `ratio`; `"20.9"`→20.9. It returns `(value, is_nil, unit_hint)`.
3. `ten_year.parse(text_path, report_vintage) -> list[dict]` with keys exactly as `fin_extract_raw` (SPEC-01 §5.3) plus `fiscal_year`, `is_restated`, `parent_label`, `block` (`physical|financial_value|financial_strength|other_information|ratio`).
   - FY columns from the header line: `2025-26`→`FY26`; a trailing `*` → `is_restated=True` for that column.
   - Values = the **last N numeric tokens** of a line (N = number of FY columns). Ignore the side-tab words ("Overview", "Standalone Financial Statements", "Annexures to the Board's Report", …) by dropping text right of column 165.
   - Label continuation: a line with no numeric tokens directly after a data line is appended to the previous label (e.g. `Depreciation, Depletion, Amortisation and` + `Impairment`; `Return on Capital Employed (%) (ROCE)` + `-incl. exceptional items` → the second ROCE row gets label `Return on Capital Employed (%) (ROCE) -incl. exceptional items`).
   - Lines starting with ` -` are children: `parent_label` = the nearest previous non-child label.
   - `unit` = `INR_mn` for the money blocks, `MMT`/`BCM`/`kT` for the physical rows (from the label), `pct` for `(%)` labels, `ratio`, `INR_per_share` for EPS, `days` for "Debtors Turnover Ratio (Days)", `count` for "Number of Employees".
   - `source_page` from rule 1; `source_text_line` = 1-based line number.
4. `ten_year.cross_check(rows_a, rows_b) -> list[dict]`: for the same (normalised label, FY) in two editions, emit `{label, fy, value_a, value_b, delta, vintage_a, vintage_b, later_marked_restated}`; `|delta| ≤ 1` (₹ mn rounding) = pass.
5. CLI: `uv run python -m financial_ssot.extract.ten_year --out financial_ssot/out/ten_year_raw.parquet` parses the three ARs and writes all rows + `financial_ssot/out/ten_year_crosscheck.csv`.
