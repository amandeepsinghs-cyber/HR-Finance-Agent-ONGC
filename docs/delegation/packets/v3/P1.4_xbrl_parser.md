## 5. Exact requirements
1. `xbrl.parse(path) -> list[dict]` using `lxml.etree` (no regex parsing of XML). Fields: bronze schema + `fiscal_year` (from the file name `FY2020-21` → `FY21`), `scope` (`standalone|consolidated` from the file name), `xbrl_tag`, `context_ref`, `period_type` (`annual` for `FourD`, `quarter` for `OneD`), `segment_member` (for dimensional contexts), `decimals`, `value_inr` (raw), `value_inr_cr = value_inr / 1e7`, `precision_inr_cr = 10**(-decimals) / 1e7` (→ 1.0 for `decimals="-7"`), `source_system='xbrl'`, `extraction_method='xbrl'`, `source_doc` = file name.
2. Non-numeric facts (descriptions, dates) are kept in a separate list `xbrl.parse_text_facts(path)`.
3. Cross-check: for tags mapped in `xbrl_tag_map.csv` to a 10-yr label, compare FourD standalone values with the P1.2 rows (₹ mn ÷ 10): `|Δ| ≤ 0.5 ₹ cr` = pass. Output `financial_ssot/out/xbrl_crosscheck.csv`.
4. CLI: `python -m financial_ssot.extract.xbrl --out financial_ssot/out/xbrl_raw.parquet`.
