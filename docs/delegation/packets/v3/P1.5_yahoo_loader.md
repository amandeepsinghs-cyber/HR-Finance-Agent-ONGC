## 5. Exact requirements
1. Statement rows: `source_system='yahoo'`, `scope='consolidated'`, `extraction_method='yahoo_api'`, `fiscal_year` from `asOfDate` (2026-03-31 → FY26), `period_type` from the key prefix (`annual`/`quarterly`/`trailing`), `yahoo_type` (e.g. `annualTotalAssets`), `value_inr` and `value_inr_cr`, `currency` (must be INR, else row rejected), `source_doc` = saved file name.
2. Price rows: `ticker, date (IST trading date), open, high, low, close, adj_close, volume, provider, source_doc`. `weekly_closes(df)` returns Friday (or last trading day of the week) adjusted closes.
3. `MarketProvider.get_prices(ticker, start, end)` tries Yahoo files → manual seed and returns rows plus `provider` used. If nothing is found, it raises `MarketDataUnavailable` (callers degrade; SPEC-02 beta fallback).
4. CLI: `python -m financial_ssot.extract.yahoo --from-files --out financial_ssot/out/yahoo_raw.parquet` (offline). `--fetch` is allowed only when O instructs.
