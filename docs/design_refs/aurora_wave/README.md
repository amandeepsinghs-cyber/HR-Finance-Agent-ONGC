# Aurora wave: approved voice orb reference (D-29)

This is the sponsor-selected voice orb for Yukti: **"C · Aurora wave"**, chosen on 22-Oct-2026 from three concepts
(A aura sphere, B breathing halo, C aurora wave). It is made of borderless, feathered bands of AI-aura light with a thin
white line through them, over a soft pastel bloom. Idle is calm, listening and speaking follow the real mic and output
levels, and thinking shows a travelling shimmer.
